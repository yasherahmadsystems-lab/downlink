# Downlink

A 3D browser game where you design a spacecraft, take it through a NASA-style design review, fly the mission and read a plain-language report of what your choices cost. Built for the **NASA Space Apps Challenge 2026**, "Space Mission Design Game" challenge, by **Team AETHELGARD** (Peshawar Local Event).

**Play:** https://downlink-eight.vercel.app/

**Source:** https://github.com/yasherahmadsystems-lab/Downlink (open source, MIT)

Built during the hackathon weekend (14–15 November 2026).

Add `?demo` to the address ([demo run](https://downlink-eight.vercel.app/?demo)) and the game plays itself once from title to report, with a visible AI-generation mark, for recording the demo video.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173. `npm run build` makes the production build in `dist/`; `npm test` runs the simulation tests.

## Use of AI (Super Intelligence disclosure)

- **Code:** written by Claude (Anthropic) under the team's direction. Source files carry a header saying so.
- **3D assets:** built by Claude as Blender Python scripts (`art/blender/`), run headless in Blender 5.2 and exported to GLB. No AI image or video generators are used for the models. The launcher, launch pad, ground-station dish and the integration hall with its thermal-vacuum chamber are generic designs that copy no real vehicle or site.
- **Data tables:** Claude helped assemble them. Every value carries a `source` field: a NASA document, or "Game balance" for values invented for play.
- **Concept, art direction, title, pitch and scoring decisions:** the team's.

## NASA data and resources

| NASA resource | Where it is used |
|---|---|
| JPL Concept Maturity Levels | The CML meter (levels 1 to 4), the 35% mass, power and energy margins, 100% software margin, 6 dB link margin, and the 80% pass rule of the design review |
| CubeSat 101 (CubeSat Launch Initiative) | CubeSat mass limits, the $300,000 launch figure, the 10% budget reserve, and the antenna-deploy (30 min) and first-beacon (45 min) timeline in flight |
| Design and Develop Science Missions | The four mission segments that organise the catalog; requirements with a verification method in the briefing |
| Mission Design Lab (GSFC) | The names of the four study levels |
| NASA Planetary Fact Sheets | Earth's gravitational parameter and radius, and solar irradiance, used for orbit period, eclipse and power |
| NASA SVS Blue Marble | The Earth in the flight scene |

Every value in `src/data/` carries a `source`. Values not taken from NASA are labelled "Game balance" in the data and in the game.

This project is not affiliated with or endorsed by NASA. It uses no NASA logos, insignia or mission identifiers.
